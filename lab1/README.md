# Лабораторная работа №1

## Проект «Электронная библиотека и каталог книг»

Вариант №18. Предметная область: электронная библиотека, в которой читатель ищет книги, бронирует доступные экземпляры, получает и возвращает их, а библиотекарь ведёт каталог и контролирует выдачу и штрафы.

### Состав работы

- [ARCHITECTURE.md](./ARCHITECTURE.md) — описание предметной области, Use Cases, C4 Container и ER-модель.
- [c4-container.mmd](./c4-container.mmd) — исходник диаграммы C4 Container.
- [erd.mmd](./erd.mmd) — исходник ER-диаграммы.
- [library_schema.sql](./library_schema.sql) — PostgreSQL DDL с ограничениями и индексами.

Диаграммы можно открыть в Mermaid Live Editor или встроить в Markdown-совместимый Git-сервис.
