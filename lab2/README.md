# Лабораторная работа №2

## REST API электронной библиотеки

Спецификация подготовлена по варианту №18 и соответствует OpenAPI 3.0.3.

- [ARCHITECTURE.md](./ARCHITECTURE.md) — REST-контракт, таблица endpoint’ов и ответы на контрольные вопросы.
- [openapi.yaml](./openapi.yaml) — готовая спецификация для Swagger Editor / Swagger UI.

Открыть интерактивную документацию можно через Swagger Editor: загрузить файл `openapi.yaml` или использовать команду `npx @redocly/cli lint openapi.yaml` для проверки.
